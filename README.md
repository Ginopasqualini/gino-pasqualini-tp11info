# TP 11 — Descongelando el Código

Minijuego web interactivo realizado con HTML5, CSS3 y JavaScript para Laboratorio de Programación, 6° G, IPET 249 Copérnico.

## Cómo jugar

- Presioná **Empezar partida**.
- Movete con **← / →** o **A / D**; también podés mover el mouse o el dedo sobre el área del juego.
- Juntá 12 orbes amarillos y evitá los bloques de hielo antes de que termine el tiempo.
- **Escape** pausa o reanuda. El botón **Pausar** también funciona.
- El récord se guarda en el navegador.

## Archivos

- `index.html`: estructura de la página.
- `styles.css`: diseño adaptable a pantallas chicas y grandes.
- `game.js`: dibujo con Canvas, controles, colisiones, puntaje y estados del juego.

No se necesitan herramientas de compilación ni dependencias. Para probarlo localmente, abrí `index.html` en un navegador.

## Publicar con GitHub Pages

1. En el repositorio, abrí **Settings → Pages**.
2. En **Build and deployment**, seleccioná **Deploy from a branch**.
3. Elegí la rama `main` y la carpeta `/(root)`, y guardá.
4. Esperá a que termine el despliegue. La URL esperada es `https://ginopasqualini.github.io/gino-pasqualini-tp11info/`.

> El repositorio se creó como privado. Para que el sitio sea público mediante GitHub Pages, verificá que tu plan permita publicar Pages desde un repositorio privado o cambiá su visibilidad a pública en **Settings → General → Danger Zone**. No cambies la visibilidad sin confirmar antes con tu docente.
